YOUR PICTURES GO IN HERE
========================

Every folder in here is waiting for your files. Drop them in, then point at
them from the matching file in src/content/. CONTENT-GUIDE.md in the main
folder explains how, in plain language.

  portraits/   the two pictures of you on the home page
  hero/        the wide picture at the entrance to Projects
  projects/    everything inside a project: photographs, drawings, process
  journal/     the picture at the top of a piece of writing
  interests/   the artwork on an interest
  archive/     sketches, working images, notes, references
  dog/         pictures of the companion, if you want it to use them

WHILE A FOLDER IS EMPTY
The website draws its own placeholder in exactly the right shape and size.
Nothing looks broken and nothing moves when you add the real picture.

FILE NAMES
Use lower case letters, numbers and hyphens. No spaces, no capitals, no
accents. Good: courtyard-plan-ground.jpg   Bad: Courtyard Plan (Ground).JPG

FILE SIZES
Save photographs as .jpg at about 2000 pixels on the long side. Save
drawings with flat colour as .png. Keep each file under about 500 KB. A
huge file will not look better on a screen; it will only load slowly.
